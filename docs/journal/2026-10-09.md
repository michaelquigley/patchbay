## desktop integration

- `patchbay desktop integrate` / `remove` is a port of gloss's command (`~/Repos/q/products/gloss/cmd/gloss/desktop.go`), the house pattern flo → ranger → gloss. Decided with Michael: plain `patchbay` id (nothing to shadow, and it must equal the window's future app id), svg-only icon (no rasterizer on this machine; GNOME renders the scalable svg), the mark drafted by the agent for his by-eye pass.
- A stale `~/.local/share/icons/hicolor/icon-theme.cache` hid the mark on first install: GTK trusts a cache newer than the theme directory, and writing into `scalable/apps/` does not touch that directory's mtime. Integrate and remove now rebuild a cache that already exists (`-f -t -i`, since a user theme dir has no `index.theme`) and never create one. Neither ranger nor gloss does this; they got away with it because their pngs were installed before the cache was written.
- Wayland window matching is open: GLFW takes the app id only from the `GLFW_WAYLAND_APP_ID` string hint, cimgui-go exposes only integer hints, and dfx sets none. GLFW is statically linked (`libglfw3.a` in cimgui-go), `glfwInit` runs in `NewGLFWBackend` and `CreateWindow` is a separate call, so dfx can declare `glfwWindowHintString` extern in its own cgo and set the Wayland app id and X11 class between the two. Michael approved dfx changes for this. Until then: a grid-launched window should match its entry by pid, a terminal-launched one shows generic. Not yet verified by eye.
- dfx gained `Config.AppID` (uncommitted in `~/Repos/q/products/dfx`). Verified with a temporary `replace` and `WAYLAND_DEBUG=1`: the window sends `xdg_toplevel.set_app_id("patchbay")`. Michael tagged dfx v0.1.14 in the same session; patchbay is bumped and sets `AppID: "patchbay"` beside `Title` in `internal/ui/app.go`. The installed binary sends the app id; that it pairs with the entry in the dock is for the by-eye pass. The id is the same string in two files, `desktopID` in `cmd/patchbay/desktop.go` and the literal in `internal/ui`, and they must stay equal.
